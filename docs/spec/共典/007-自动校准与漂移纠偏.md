# 007 · 自动校准与数值漂移纠偏

> **来源**：[GitHub #8 解法评论](https://github.com/YunxiLuna/TRPGTogether/issues/8)（方式：grilling 1 轮，4 题全按推荐拍板）。
>
> **为什么（人类可读）**：本票攻坚简报 D 题——不靠人工，怎么自动判断"这次数值提议是否离谱""当前阶段节奏是否透支"，以及连续偏离时怎么发现并纠偏。设计默认输入=横切「LLM token 不宽裕」约束：**全票 LLM 调用点仅 1 处（Q3 叙事注入，喂小切片），判定/发现/纠偏触发/自适应全走纯规则零 token**。核心=纯规则三重判定（世界书锚点/schema cap/节奏预算）取 min 打 suspect + 物化视图滑动窗口漂移发现 + 四动作纠偏全走账本可回滚 + 密度复用 003 识别信号 3 档曲线。

## Q1 离谱判定（至少 2 种机制比较 → 选纯规则三重判定 + suspect 标签，零 token）

- **机制 1（选定主）纯规则三重判定，取 min 作阈值**：
  1. **世界书锚点**：003 三级锚定位的最近 schema 锚点值（quantity 的 cap/区间边界），提议值距锚点超容差→离谱；
  2. **schema 边界**：该 quantity 的 `{min,max,cap?}`（003 Q2）越界即离谱；
  3. **节奏预算透支**：本阶段该数值体系总预算累计透支检测（"该爽时保守"的反向——透支=前期把预算花光，后续无戏可唱）。
  任一判据命中→引擎自动打 **suspect 标签**（004 例外模式 3）+ 写账本 `calibration_check{seq,ts,actor,prop_value,thresholds_hit[],suspect:true}`，**不阻塞叙事**。
- **机制 2（增强信号）k σ 分布检测**：需历史提议分布统计，冷启动无样本不可靠→**降为增强信号不作主判据**。
- **拒绝全量 LLM 判定**（每个提议调用 1 次 LLM=调用点爆炸，不可回算）与 **LLM 语义辅助**（不可回算，违背账归代码）。

## Q2 漂移发现（连续多轮偏离 → 物化视图滑动窗口 + 趋势斜率，零 token）

- **账本 tail 推进时增量算**该属性近 W 轮提议值相对 schema 期望的偏差均值/趋势斜率 + suspect 累计计数（物化视图，与 006 panel_state 同构，不重放全量）；
- 超阈值（**连续 N 轮 suspect 或斜率超 k**）→ 追加 `drift_alert{seq,ts,attr,window,W,slope,suspect_streak}` 事件 + 推 GM 监控区（006 Q5 入口），不静默；
- **LLM 定期回顾降级为 GM 手动触发的深挖按钮**（非自动路径，不每轮跑——全系统第 2 个 LLM 调用点，drift_alert 累计 ≥3 次时 GM 可手动点，喂该属性全部叙事历史+世界书三级锚原文段做 1 次深度比对，token 克制）；
- 拒绝仅 suspect 计数（缺斜率抓不到"连续小幅偏离"的早期趋势）与 LLM 定期回顾（不可复现、不可回算、违反 token 克制）。

## Q3 纠偏动作（四动作全走账本可回滚，append-only 不删不改，可组合）

1. **拒绝离谱提议**：suspect 标签事件 + 该提议不进正典（降级临时/传闻，`canon_status` 走 005 的 status_transition）；
2. **强制回退**：追加 `status_transition` 把该属性回退到最近 schema 锚点值（003 三级锚定位），账本记 `drift_correction`；
3. **向 GM 告警**：drift_alert 推 GM 监控区（006 Q5 已有入口，零额外结构）；
4. **注入"世界在修正自身"叙事**：由 LLM 生成一段叙事（**本票唯一允许的 LLM 调用点**，喂漂移指标 + 相关世界书切片，小上下文），写账本 `narrative_correction`。
- **回退可回滚**：回退是追加的账本条目，后续剧情可自然演进回去；误纠偏（阈值设太紧把正常波动打 suspect）再追加反向 transition，原条目永存可审计。
- 拒绝"只拒绝+告警"（漂移纠不回来、丢产品卖点"世界在自愈"）与 LLM 自主决策纠偏（不可回算、token 爆炸）。

## Q4 自适应严格度（密度复用 003 识别信号 + 3 档曲线，零 token）

- **密度 = 该世界书"可量化体系数量 × 消费度加权"**（复用 003 Q1 置信度之消费度，纯规则算，零额外 token——003 三档置信度已含结构×消费度×一致性，直接取用不另造 LLM 估密度）；
- **严格度曲线 = 密度 3 档分段映射**：高→收紧（k σ 更小/漂移窗口 W 更短/suspect 更易触发）；中→默认；低→放宽（纯文学世界书几乎不量化，别卡死叙事——"校准纯规则阈值在纯文学世界书（密度低档）下是否形同虚设"的答案=**低档放宽阈值即近 no-op 是设计选择非缺陷**，纯文学世界书本就不该硬卡数值）；
- 曲线形状由 003 置信度分布自动定，**无人调参**；
- 拒绝 LLM 估密度（多一次冷启动调用且不可复现）与恒定严格度（违背已知结论"随密度自适应"）。

### 落地 map 的 4 条雾

- **S2 门控密度（004 Q6 留的一半）** = Q4 密度 3 档之高档（S2 逃生门开启条件②"007 判密度高"由此落地）；
- **承重量 N 与权重（003 Q5b 留的一半）** = Q2"连续 N 轮该属性被叙事引用/结算消费"累计，权重=消费度加权，N 与权重随 3 档曲线缩放；
- **回算容差（003 留给 007 内定）** = Q1 锚点判据取 min 阈值，容差=quantity cap 区间相对误差带，随 3 档曲线缩放；
- **校准密度指标 + KnownSet/panel_state 漂移监控触发时机（005/006 留）** = Q2 账本 seq 推进即增量刷（O(1) 与 panel_state/KnownSet 同构同频，无全量重放），密度指标=Q4 可量化体系数×消费度加权。

## 场景走查（本票机制端到端验证）

> 「剑意值连涨三轮」：cap=50，正典 34，节奏预算累计涨幅 ≤30
>
> - 轮 1：提议 +10→44，正常（cap 内、节奏未触顶）；
> - 轮 2：提议 +12→56，越 cap → 打 **suspect**（streak=1），不阻塞叙事；
> - 轮 3：提议 +8→64，越 cap + 节奏触顶双判据命中（streak=2）→ **drift_alert** → 四动作纠偏（拒绝 64 / 强制回退 34 / GM 告警 / LLM 注入"世界在修正自身"叙事）；
>
> 世界自愈，全程无人工调参。

## 放弃项（本票明确不做的方向，供 /implement 不越界参考）

- 全量 LLM 离谱判定（调用点爆炸、不可回算）；
- LLM 语义辅助（不可回算，违背账归代码）；
- LLM 定期回顾（不可复现、不可回算、违反 token 克制——降级为 GM 手动深挖按钮非自动路径）；
- 仅 suspect 计数（缺斜率抓不到早期小幅趋势）；
- 只拒绝+告警（漂移纠不回来、丢产品卖点）；
- LLM 估密度（多一次冷启动调用且不可复现，不如复用 003 已算好的识别信号）；
- 恒定严格度（违背"随密度自适应"已知结论）。
