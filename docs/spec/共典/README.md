## 全局不变量（所有子文件共同遵守，摘自 map #1 注意区）

1. 故事归 AI，账归代码——LLM 只提议数值，引擎（解释器）唯一结算。
2. 事实分临时/正典两级；LLM 可即兴发明，提升正典需自动校验。
3. 事件账本 append-only，文件为事实源，数据库为可重建索引。
4. 多人异步优先；缺席玩家收"角色内视角的谣言/简报"。
5. 冲突先提交者正典，后提交者仲裁为旁支/传闻。
6. 校准严格度随世界书"可量化密度"自适应，该评估自动完成。
7. LLM token 不宽裕（横切 standing preference）——少调用、小 prompt、缓存、物化视图避免重复推导。
