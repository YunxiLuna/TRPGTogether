## 一句话结论

样本A（斗罗）是"面板型爽文"：数值几乎全部集中在章节 2/3/15/17，形态稳定（等号、"N = M"、伪表格行、面板框线），**适合确定性 schema**。样本B（修仙）是"体系型文游"：数值散在 40 个"卷"里，大量表格以"表头行+数据行"两段式文本出现，且突破概率、寿元、好感度这类量都给出了**显式公式**，可量化密度反而更高，但**同一量在多处重复定义**（突破概率在第三卷与第三十六卷各写一遍），schema 设计必须处理"跨卷去重/一致性"问题。

> 摘录 3（15.1 速查表，三列：等级/称号/对应魂导器等级）：
> "1-10 魂士 0级 / 11-20 魂师 1级 / … / 91-99 封号斗罗 9级 / 100+ 神级 10级"

> 摘录 1（第三卷·一 人界九境 + 寿元表）：
> "练气 80~120年 引气入体，初窥门径 / 筑基 150~200年 …… / 渡劫 5万年+ 渡劫飞升，或兵解转世"

> 摘录 1（2.5 积分商店，物品/价格区间）：
> "普通魂骨 100-500 / 外附魂骨 2000-5000 / 十万年魂环 3000 / 凶兽魂环 8000 / 神赐魂环 20000 / 斗铠锻造材料（四字） 20000 / 超神器胚胎 100000"

> 摘录 2（2.6 装逼值商店 + 15.3 速查，货币→兑换物，整数比）：
> "装逼值 可兑换：100 气运加持 / 500 魂环升年限 / 1000 武魂进化 / 3000 随机外附魂骨 / 5000 凶兽魂灵 / 10000 神赐魂环 / 50000 神位碎片合成 / 100000 超神器进化 / 1000000 创世神之路"

> 摘录 3（2.4 签到系统，时间→货币+物品的阶梯）：
> "连续签到天数 奖励：1天 积分+10 / 3天 积分+50 / 7天 积分+200，随机魂骨×1 / 14天 积分+500，百年魂环×1 / … / 365天 积分+50000，十万年魂环×1"

**样本B（修仙）** —— 出处：第六卷"拍卖会系统"、第二十九卷"详细拍卖品表"、第七卷"宗门建筑"。拍卖是最主要的交易形态，按"规模×货币"分表。

> 摘录 1（第六卷·三 小型拍卖会）：
> "拍品 品阶 起拍价：筑基丹方 二品 1000灵石 / 凝金丹方 三品 5000灵石 / 凡炉 凡品 500灵石 / 灵炉 灵品 5000灵石 / 聚灵草 一品 10灵石 / 地髓花 二品 50灵石"

> 摘录 2（第二十九卷·二 大型拍卖会，量级跨 5 个数量级）：

### 4. 显式公式（伤害=攻击力×系数−防御 之类）

**样本A（斗罗）** —— 出处：2.2 装逼值系统、17.3 结算记录。核心机制"装逼值"给了一整张"触发类型→公式"表，是样本A里唯一真正的"公式型"量化。

> 摘录 1（2.2 装逼值获取方式，"×倍数"公式）：
> "越级挑战胜利 100×等级差 / 以一敌多获胜 200×人数 / 秒杀越级对手 500×等级差 / 在极限斗罗面前装逼 ×5倍率 / 在神王面前装逼 ×20倍率"

> 摘录 2（17.3 装逼值结算记录，把公式拆开成可验算的项）：
> "基础装逼值：500 / 人数倍率：×1.5 / 身份倍率：×2（魂圣在场） / 最终装逼值：+1500"（500×1.5×2=1500，可验算）

> 摘录 3（12.3 战斗系统，战力是"多因子综合"但未给系数）：
> "战力值由魂力等级、魂环配置、魂骨数量、魂导器品质、武魂品质、斗铠等级、神位等级综合计算" —— 只有变量清单，**无系数、无公式**，属"有信号、公式缺失"。

**样本B（修仙）** —— 出处：第三卷"突破机制"、第三十六卷"突破机制详解"。突破成功率是三份样本中**显式程度最高**的公式，直接写成等式。

> 摘录 1（第三卷·4.1 丹药突破，显式加和公式）：
> "丹药突破成功率加成：阵法辅助 +5% / 符箓辅助 +5% / 双修辅助 +10% / 特殊体质 +10% / 气运影响 ±5% / 宗门灵气 +5% / 天时地利 +5%。上限95%。"（基础成功率见突破丹表，如 练气→筑基 筑基丹 60%）

> 摘录 2（第三卷·4.3 混合突破，乘法+截断公式）：
> "总成功率 = 丹药基础 + 强行加成 × 50% / 失败后果：丹药效果反噬 + 强行突破反噬，双重打击"

> 摘录 3（第三十六卷·二 强行突破，属性→概率的线性系数）：
> "加成：悟性每50点 +1% / 气运每50点 +1% / 体魄每50点 +1% / 特殊体质 +3~5% / 天道眷顾 +5%。上限15%。"（基础概率表：练气→筑基 10% … 太乙→大罗 2%）

**可量化性判断**：这是**最值得优先建 schema 的一类**。样本B的"成功率 = 基础 + Σ(加成)，且各有上限（95%/15%）"已经是可执行的数值规则；样本A的"装逼值 = 基础 × 人数倍率 × 身份倍率"同样可执行。两者都给了"上限"，schema 要带 `cap` 字段。斗罗的战斗战力公式只给了因子没给系数，是**半公式**，schema 里可建 `factors[]` 但 `weight` 留空。

**样本A（斗罗）** —— 出处：6.5 创世神、9.6 神位面板、7.4 创世神线。以"神位碎片 0/1、集齐四大神位解锁创世神"为代表。

> 摘录 1（6.5 创世神解锁条件，多项计数门槛）：
> "集齐海神、修罗神、毁灭神、生命神四大神位碎片 / 击败神界五大至尊中至少三位 / 拥有至少一个超神器级别的外附魂骨 / 装逼值累计达到1000000点"

> 摘录 2（9.6 神位面板，进度计数器格式 `x/N`）：
> "神位碎片：海神碎片：0/1 / 修罗神碎片：0/1 / 毁灭神碎片：0/1 / 生命神碎片：0/1"

> 摘录 3（6.4 系统独家神位，"完成 N 个隐藏任务"型计数）：
> "因果神……需在成神之前完成至少100个隐藏任务，且从未使用过'气运加持' / 万兽神……需与至少10个凶兽级魂灵签订契约"

**样本B（修仙）** —— 出处：第七卷"宗门系统"、第三十八卷"灵兽化形"。以"忠诚度/境界达 N 解锁化形""万宗大比排名"为代表。

> 摘录 1（第三十八卷·一 化形条件，多条件 AND 计数）：

> 摘录 2（第七卷·二 弟子系统，进度型数值）：

> 摘录 3（第四十卷·四 宗门声望榜，排名计数）：

**可量化性判断**：样本A的 `0/1` 碎片计数与"≥100 任务"是标准 `progress: int / target: int` 与 `count ≥ N` 谓词，极易进 schema。样本B的"化形"是 `AND(等级≥5, 忠诚≥80, 道具)` 组合谓词。"声望榜"是 `rank` 字段。这一类信号**结构简单但容易漏判**——因为它们常散落在"解锁条件""剧情线"叙述里（如样本A 7.4），不在面板区。

### 6. 状态机（阶段/职业/境界的跃迁条件）

**样本A（斗罗）** —— 出处：7.2/7.3 主线剧情线、6.4/6.5 神位。剧情线按"魂力等级区间→幕"切分，本质是状态机。

> 摘录 1（7.2 主线剧情线，阶段=境界区间，跃迁条件=魂力等级）：
> "第一幕：觉醒（魂士→大魂师）/ 第二幕：锋芒（魂尊→魂帝）/ 第三幕：风暴（魂圣→封号斗罗）/ 第四幕：弑神（超级斗罗→神级）/ 第五幕：神界新星（神官→三级神祇）……"

> 摘录 2（12.2 魂环获取，等级阈值触发事件）：
> "魂力每达到10/20/30/…/100级时，触发魂环吸收事件"（离散阈值事件）

> 摘录 3（6.4 神位跃迁，职业分支）：
> "成神试炼中击败时间与空间的守护者……需拥有时空类武魂，并在成神时选择'时空之路'"（条件→解锁分支）

**样本B（修仙）** —— 出处：第三卷"突破机制"、第三十六卷。境界跃迁有**三条并行路径**（丹药/强行/混合），且每条有触发条件与失败后果，是比样本A更复杂的状态机。

> 摘录 1（第三卷·四 突破机制，三路径）：
> "4.1 常规突破（丹药）——主流，成功率最高 / 4.2 强行突破（无丹药）——高风险，高回报 / 4.3 混合突破——丹药保底 + 强行爆发"

> 摘录 2（第三卷·4.2 强行突破触发条件枚举）：
> "触发条件：生死绝境 / 情绪爆发（大悲、大怒、大爱）/ 顿悟 / 血脉觉醒 / 传承灌顶 / 天劫余波 / 特殊秘境 / 神魂交融（双修极致）"

> 摘录 3（第三卷·4.2 失败后果状态分支）：
> "轻 重伤，境界停滞 / 中 走火入魔，跌落境界 / 重 寿元减半 / 极重 身死道消"（同一事件 4 个终态，是典型状态机）

**可量化性判断**：样本A的状态机是"线性剧情幕+阈值事件"，状态少、边少，`state_graph` 很小。样本B的"突破"状态机是**带概率与分支的有限状态机**（成功/4 级失败/跨境界/获词条多终态），且路径三选一，schema 价值最高但建模成本也最高。

## 反例：看似可量化、但保持自然语言更合适

任务要求记录两类。样本中"悟性""道心"这类模糊属性确实出现，但更准确的反例是**"有名字、有方向感、却没有数值定义"的属性**——它们适合留自然语言，强行数字化会失真。

**反例 1：样本B 的"气运"（命运类模糊量）**
出处：第二卷·核心属性表 第 1 行。

> 摘录（第二卷 核心属性表）：
> "气运 奇遇、爆率、拍卖捡漏、避劫 1~100 1000"

"气运"在表里被给了 `1~100` 的初始范围和满值 1000，**看起来**是可量化属性。但实际用法（第四卷词条"气运之子 奇遇概率翻倍"、第六卷"气运影响 ±5%"、第三十八卷"共享气运"）它更多是**叙事性随机性的代名词**，玩家/AI 真正需要的是"这个属性高→奇遇更容易发生"的**方向语义**，而不是精确 1~100 数值本身。把它建成 `int` 字段可行，但真正驱动玩法的是"高/中/低"三档语义。→ 建议 schema 里保留数值但**额外存 `narrative_role: "luck"`**，或干脆用"气运高/中/低"枚举而非 1000 级整数，避免假精度。

**反例 2：样本A 的"装逼值"（社交情绪量）与 样本B 的"魅力"（关系模糊量）**
出处：样本A 2.2 装逼值系统；样本B 第二卷 核心属性"魅力 结缘、收徒、NPC态度 1~100 1000"。

"装逼值"虽然样本A给了一整张公式表，但它本质是**"他人震惊程度"的货币化**——"根据在场人数和身份决定""目击者越多，装逼值越高"（8.3）。它的"数值"其实是**社交事件的强度**，精确值在运行时才产生，设计文档里的 100/500/1000 只是**档位锚点**而非可独立运算的量。同理"魅力"在样本B里只给"1~100/满值1000"，没有任何公式消费它（它只出现在"结缘、收徒、NPC态度"这种模糊用途里，没有"魅力每 N 点 +X%"的系数）。→ 这类"有数值壳、无消费公式"的属性，**保持自然语言档位（低/中/高）比建 1000 级整数列更贴合实际玩法**，schema 里建议存 `enum + optional_cap` 而非裸整数。

> 小结：真正的反例判据是 **"有没有被某个公式/规则实际消费"**。被消费（气运 ±5%、悟性每 50 点 +1%）→ 量化；没被消费、只当叙事方向（魅力 1~100 但无任何 +X% 规则吃它、装逼值的"基础"靠运行时产生）→ 自然语言档位更合适。

### 最容易被自动识别（结构明确）

- **显式公式**（样本B 突破成功率）：文本里有 `=`、`+`、`×`、`上限 N%` 这些强 token，正则/LLM 抽取置信度最高。
- **颜色/品阶映射**：`白→绿→蓝→紫→橙→红→金` 这种一行色阶链 + `颜色 年限 说明` 三列伪表格，列头稳定，是确定性解析的首选目标。
- **兑换价目表**：`物品 价格` 两列、`拍品 品阶 起拍价` 三列，列头反复出现，跨行模式一致。

### 最容易被漏判（藏在叙事里）

- **收集/进度计数**：大量以"集齐……碎片""完成至少100个隐藏任务""忠诚度达到80以上"的**叙述句**形式散落在剧情线/神位章节（样本A 6.4/6.5/7.4），不在面板框线内，自动识别容易当成普通叙事漏掉。
- **状态机**：样本A 的"主线八幕（境界区间→幕）"埋在第七章剧情叙述里；样本B 的"失败 4 后果（重伤/走火入魔/寿元减半/身死道消）"在"程度 后果"小表里，但表头不显式，且 16/35 卷的 GM 原则又把"可强行突破"用散文重复了一遍，跨卷散落。
- **货币档位换算比**（数据缺口）：样本B 的"灵石（下/中/上/极品/灵晶）"给了 5 档枚举但**全文无 1:1 换算数值**，这是"有信号、缺数据"，自动识别会得到一个空字典，需人工补。

### 对 schema 设计的直接提示（仍属描述，非设计本身）

- 同一量跨卷/跨章**重复定义**是两份样本的共性：样本A 魂环色映射写 2 次（3.3 vs 15.2，稀有度用词不一致）、装逼值速查写 3 次（2.6/15.3/8.2 建议）；样本B 突破概率写 2 次（第三卷 vs 第三十六卷）、属性表写 2 次（第二卷 vs 第三十二卷）、弟子表写 2 次（第七卷 vs 第二十六卷）。→ schema 需"量纲唯一 + 多出处引用"，而非按出现次数建多份。
- 数值量带"区间/上限"普遍（`100-500`、`80~120年`、`上限95%`），字段设计用 `{min, max, cap?}` 而非单值。
